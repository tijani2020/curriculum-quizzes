# Curriculum quizzes

Ready-made quizzes for **SchoolEnjoy**, written against the national programme.

Teachers do not need this page. Open **SchoolEnjoy → Saved quizzes**: the list
appears there, and one click puts a quiz on the laptop, where it stays and plays
without internet.

Each file under `quizzes/` is one quiz — its questions, the audio that reads them
aloud, and its pictures, all in one file. `index.json` is the list the app reads.
